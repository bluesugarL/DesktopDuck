# 💻 桌宠牢鸭 (DeskDuck)

一款专门为《棕色尘埃2》B站大主播 **咕咕鸭** 深度定制的开源桌面宠物程序！
不仅完美还原了咕咕鸭的激萌（牢人）形象，还融入了丰富的互动玩法。让他常驻你的桌面，在你敲代码、看视频、抽卡时提供最忠诚的陪伴（或者是血压拉满的碎碎念）。

---

## ✨ 核心功能 (Features)

### 👗 自由换装（Outfit System）

内置多套独家精致皮肤（包括主播经典装扮、游戏联动梗服等），一键切换，让牢鸭每天都有新造型。

### 🍖 趣味投喂（Feeding System）
可以通过桌面交互喂食各种奇奇怪怪的道具。
*注意：投喂不同食物会触发截然不同的鸭鸭动态反馈哦！*

### ❤️ 好感度羁绊（Affection System）

通过日常点击、抚摸、投喂累积好感度。随着好感度等级解锁，将会触发隐藏动作、专属语音/弹窗台词，甚至能解锁特殊限定换装！

---

## 🚀 快速开始 (Quick Start)

### 方案 A：直接打包下载（适合普通粉丝）
1. 前往本仓库的 **Releases** 页面。
2. 下载最新的 `桌宠牢鸭_Vx.x.x.exe`。
3. 双击运行即可让鸭鸭降临桌面！

### 方案 B：本地开发与运行（适合开发者）
如果你想为牢鸭开发新的皮肤或功能，欢迎 Fork 本仓库！
